# Документация Office Monitor
Этот каталог — единая точка входа для актуальной документации проекта.
## Основные документы
- `docs/DEPLOYMENT.md` — развёртывание, обновление и проверка состояния.
- `docs/REPOSITORY_FLOW.md` — рабочий flow для `main` + `frontend` submodule + `docker-01`.
- `docs/AGENT_SETUP.md` — установка и сопровождение Windows-агента.
- `docs/LOGGING.md` — правила и примеры логирования.
- `docs/AI_CONTEXT.md` — контекст для AI-агентов и контрольные точки по legacy backup.
- `grafana/README.md` — настройка Grafana и импорт дашбордов.
## Что было очищено
Из репозитория удалены одноразовые скрипты и устаревшие task-артефакты, которые не участвуют в текущем процессе разработки/деплоя.
История не потеряна:
- через `git log`;
- через backup-ветку в GitHub (`backup/pre-cleanup-*`);
- через сохранённые backup-каталоги (см. `docs/AI_CONTEXT.md`).
## Принцип поддержки документации
1. Любой новый операционный процесс фиксируется в `docs/`.
2. Если документ временный (исследование/черновик), он не хранится в корне репозитория.
3. Изменения в flow деплоя и submodule обновляются одновременно в `docs/REPOSITORY_FLOW.md` и `docs/DEPLOYMENT.md`.
